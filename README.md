Tiny lesson: Introduction to AI
Artificial intelligence (AI) is technology that enables computers to perform tasks that usually require human intelligence, such as recognizing images, understanding language, and solving problems. Machine learning (ML) is a type of AI that allows computers to learn patterns from data and make predictions without being given specific rules for every situation. Therefore, machine learning is a part of AI, but not all AI uses machine learning.
For example, an email spam filter can learn from previously labelled emails to identify patterns commonly found in spam. It then uses these patterns to classify new emails. However, it might mistakenly mark a legitimate email from a university lecturer as spam. This shows that AI can make errors and its decisions may need human review.
